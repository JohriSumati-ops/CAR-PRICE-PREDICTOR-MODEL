# 🚗 Car Price Prediction Web App 📈

A machine learning–powered **web application** that predicts the **selling price of a car** based on its features such as brand, year of manufacture, fuel type, transmission, and mileage.  
The project combines **machine learning** with an interactive **Streamlit web interface** for real-time predictions.

---

## 🌐 Web Application
The model is deployed as a **Streamlit web app**, allowing users to enter car details and instantly receive a predicted price.

https://unlured-tianna-northernmost.ngrok-free.dev/

---

## 📊 Dataset
The dataset contains historical car information including:
- Car Brand / Name  
- Year of Manufacture  
- Fuel Type  
- Transmission  
- Selling Price  
- Present Price  
- Kilometers Driven  

The target variable is **Selling Price**.

---

## 🛠️ Tech Stack
- Python  
- Pandas  
- NumPy  
- Scikit-Learn  
- Streamlit  
- Matplotlib / Seaborn  
- Jupyter Notebook  

---

## 🧠 Model Overview
This project uses **supervised machine learning (regression)** techniques to estimate car prices.  
The data is cleaned, encoded, and scaled before training the model.

---

## 🤖 Algorithms Used
- Linear Regression  
- Random Forest Regressor  

The **Random Forest Regressor** was selected as the final model due to its ability to model non-linear relationships and provide better prediction accuracy.

---

## 📈 Model Evaluation
The model was evaluated using:
- R² Score  
- Mean Absolute Error (MAE)  
- Mean Squared Error (MSE)  

The final model performs reliably on unseen test data.
